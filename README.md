# RIM AgroOvin Connect

Site statique publié avec GitHub Pages.

- `index.html` : portail public (point d'entrée).
- `html/` : pages de l'espace client (`client.html`) et de l'espace équipe (`equipe.html`).
- `css/` : feuilles de style, une par page.
- `js/` : scripts, un par page. `js/config.js` contient l'adresse et la clé publique Supabase.
- `espaces/` : anciennes adresses, qui redirigent vers `html/`.
